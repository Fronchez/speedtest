# Free Case Simulator

Полноценный бесплатный SPA-симулятор кейсов и апгрейдов CS2. Проект не использует реальные платежи, не выполняет Steam OAuth и хранит демо-состояние только в `localStorage` браузера.

## Возможности

- Главная страница со статистикой демо-профиля.
- Несколько виртуальных кейсов с разной стоимостью и весами выпадения.
- Инвентарь с выбором предметов.
- Апгрейд выбранного предмета с расчётом шанса успеха.
- Контракты обмена из 3–10 предметов.
- Бонусные задания и промокоды.
- Профиль, история событий, сброс демо и переключатель демо-Steam.

## Команды

```bash
npm install
npm run dev
npm run check
```

Также проект можно открыть через любой статический HTTP-сервер, потому что он написан на нативных ES-модулях.
